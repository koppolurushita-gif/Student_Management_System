# Student Management System

A console-based Student Management System developed using Java. The application allows users to manage student records through CRUD operations and demonstrates Object-Oriented Programming, Java Collections, and exception handling.

## Features

* Add a new student
* View all students
* Search student by ID
* Update student details
* Delete student
* Custom exception handling for students not found
* Input validation and exception handling
* Uses `ArrayList` for student data management

## Technologies Used

* Java
* Object-Oriented Programming
* Collections Framework
* ArrayList
* Exception Handling
* Eclipse IDE

## How to Run

1. Clone the repository.
2. Open the project in Eclipse.
3. Make sure Java is installed and configured.
4. Run `Main.java` as a Java Application.
5. Select an option from the menu and manage student records.
